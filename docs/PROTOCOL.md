# StarPleiades STM32 串口协议

## 帧格式

`A5 5A | version:u8 | flags:u8 | sequence:u16 | command:u16 | length:u16 | payload | CRC16:u16`

版本 1；所有多字节字段小端。payload 最大 128 字节，接收超时 100 ms。CRC16/CCITT-FALSE：poly=0x1021、init=0xFFFF，覆盖 version 到 payload。
flags：0 请求、1 应答、2 主动遥测。应答/状态事件 payload 首字节为状态码：0 成功、1 长度错误、2 不支持、3 范围错误、4 状态拒绝、5 忙、6 内部错误。

基础命令：1 版本、2 设备 ID、3 能力、4 状态、5 参数读、6 参数写。参数 ID 1 为遥测周期：读取 payload 为 `id:u16`，写入为 `id:u16 + value:u16`。各设备限制不同，先查能力。

编解码与分发在 `services/protocol`，不直接调用硬件或修改控制状态。中断交接数据，通信任务拥有解析器和发送；项目 `business` 回调通过业务接口提交或查询。分包、粘包、异常帧与队列丢包恢复由解析/传输层处理。旧客户端不兼容 v1，需配套固件和客户端。

## 底盘接口

UART1，115200。速度命令 `0x1000`：三个 LE f32，依次为 vx、vy、wz，单位 m/s、m/s、rad/s；范围分别 ±2、±2、±6。只提交队列，不直接改闭环；ACK 表示入队成功。

状态命令 4 / 状态事件共 31 字节：`status:u8 + state:u8 + vx:f32 + vy:f32 + wz:f32 + wheels:u8 + voltage:f32 + acc[3]:i16 + gyro[3]:i16`。
状态 0 idle、1 active、2 欠压、3 超时；IMU 量程配置为 acc ±2g / gyro ±500deg/s，仍需实物核对。

## 参数、保存与诊断


协议帧/原状态包保持 v1。能力新增 bit3（参数持久化）和 bit4（诊断）。
参数1仍为 LE u16 遥测周期，50..1000ms；其余参数读入参为LE u16 ID，成功数据为LE f32；写入参为LE u16 ID+LE f32。

| ID | 含义与单位 | 范围 |
|---|---|---|
| 0x100 | 速度环Kp，PWM计数/(m/s) | 0..10000 |
| 0x101 | 增量PI的Ki，PWM计数/(m/s)/10ms控制步 | 0..2000 |
| 0x102 | 麦轮几何半跨度之和，m | 0.05..1 |
| 0x103 | PWM上限，计数 | 1..16700 |
| 0x104 | 最低电压，V | 6..24，不能降低既有保护 |
| 0x105 | 指令超时，ms，整数 | 50..500，不能放宽既有超时 |
| 0x106 | 现有编码器速度换算的统一倍率 | 0.25..4，方向及硬件实例保留板级配置 |

不支持切换电机拓扑/引脚。芯片和编码器分辨率未验证，不把这些值当作标定结果。
调参必须先停止发速度命令，并等待状态不为active；反馈速度必须有限，平移<=0.02m/s、旋转<=0.1rad/s；保存还要求电压高于当前低压阈值。配置队列深度1，控制任务按值接收、重新初始化PI。
有未消费速度命令、配置待应用或保存维护锁时拒绝配置/新速度命令。ACK表示已入队；再次读取参数或诊断revision确认应用，之后再写下一项。

0x1001无入参：显式保存。检查停止状态、关闭PWM、确认维护锁后保存；保存期间拒绝速度命令，释放时清空旧命令，不自动恢复运动。
保存内容包括所有底盘参数及当前遥测周期。仅修改参数不会自动擦写Flash。
成功响应表示记录已写入并验证；超时可能已经提交，先重新查询diagnostics/读取参数再重试。
0x1002无入参：成功数据按顺序为7个LE u32（已应用revision、持久化sequence、RX丢包次数、解析拒绝次数、解析超时次数、TX失败次数、控制超期次数），最后u8为启动时成功载入参数标志。

### 持久化与分区

STM32 Flash末尾两个128KiB扇区6/7专用：0x08040000、0x08060000。
链接器将应用区限制为256KiB，任何新固件不得覆盖该区域。下载使用program固件，禁止在需要保留参数时整片擦除。
Flash供电范围使用既有3.3V逻辑供电配置（HAL VOLTAGE_RANGE_3）；上板前确认供电。
同bank擦除会阻塞指令取用/中断；停止维护模式用于隔离闭环，UART可能丢帧，主机保存超时设15秒。
两个副本使用独立擦除单位；magic/kind/schema/长度/sequence/CRC32/最后提交标记，不保存C结构体内存布局。
无有效记录恢复板级默认值；校验失败回退旧副本。相同内容重复保存不擦写，避免无谓损耗。
磨损寿命需要按实物datasheet、温度和写入次数评估；本实现每次变更轮换扇区，没有无限寿命承诺。
